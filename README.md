# WebGL 기반 오픈월드 환경의 객체 상호작용(기믹) 시스템 구현

컴퓨터그래픽스 기말 프로젝트입니다. WebGL 2로 만든 1인칭 3D 공간에서 큐브를 돌려 퍼즐을 풀면 길을 막고 있던 벽이 사라집니다.

- 📄 [발표자료 (PDF)](<Web GL 기반 오픈월드 환경의 객체 상호작용(기믹) 시스템 구현.pdf>)
- 🎬 [시연동영상 (MP4)](<시연동영상.mp4>)

## 기믹

- 맵 가운데에 반투명 벽돌 벽이 있어서 건너편으로 갈 수 없습니다.
- 내 쪽 큐브와 벽 건너편 큐브는 옆면이 각각 빨강·초록·파랑·노랑으로 칠해져 있습니다.
- 내 쪽 큐브를 마우스로 좌우 드래그하면 90°씩 돌아갑니다. 건너편 큐브와 색 배치를 맞추면 클리어됩니다.
- 클리어하면 벽이 사라지고, 큐브 위·아래 면의 텍스처가 바뀝니다.

## 조작법

| 입력 | 동작 |
|------|------|
| `W` / `S` | 앞 / 뒤로 이동 |
| `A` / `D` | 왼쪽 / 오른쪽으로 회전 |
| `Space` | 점프 |
| 마우스 좌우 드래그 | 큐브를 90° 회전 |
| 마우스 휠 | 줌(FOV 조절) |

## 구현 내용

- 원근 투영과 `lookAt` 카메라를 이용한 1인칭 시점
- 맵 경계 처리와 벽 충돌 감지
- 중력을 적용한 점프
- 바닥·벽·큐브 텍스처 매핑(밉맵 사용)
- 상수 알파 블렌딩으로 만든 반투명 벽
- 셰이더 2종: 텍스처 셰이더, 단색(uniform color) 셰이더

## 실행 방법

셰이더 파일을 XHR로 불러오기 때문에 `FinalProject.html`을 그냥 더블클릭해서 열면 동작하지 않습니다. 로컬 서버를 띄워서 실행하세요.

```bash
cd FinalProject
python -m http.server 8000
```

브라우저에서 http://localhost:8000/FinalProject.html 을 엽니다. VS Code의 Live Server 확장을 써도 됩니다. WebGL 2를 지원하는 브라우저가 필요합니다.
